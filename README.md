# shopping-cart-oop-javascript
A simple and interactive Shopping Cart project built using JavaScript OOP concepts. Features include adding and removing products, automatic total price calculation, and a 10% discount system on purchases of Rs. 10,000 or more. Built with HTML, CSS, and JavaScript.
🛒 Shopping Cart System – JavaScript OOP

A simple and interactive Shopping Cart System built using HTML, CSS, and JavaScript with Object-Oriented Programming (OOP) concepts.

🚀 Features
Add multiple products to the shopping cart.
Remove products from the cart.
Automatically calculate the total price.
Apply a 10% discount on purchases of Rs. 10,000 or more.
Dynamically update cart items and prices.
Responsive and modern user interface.

💡 How It Works
Select a product from the available product cards.
Click the Add to Cart button.
The selected product appears in the shopping cart.
The total price is calculated automatically.
A 10% discount is applied when the cart total reaches Rs. 10,000.
Click Remove First Product to remove the first product from the cart.
